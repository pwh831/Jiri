## 3. 퀴즈에 넣지 않은 학습지 내용

퀴즈는 **"지도 → 지명 / 지명 ↔ 특징"** 구조라, 지도 항목이 아닌 내용은 담기지 않습니다.
아래는 학습지 본문이지만 퀴즈에 없는 것들입니다. **시험 범위에는 포함되니 학습지로 따로 보셔야 합니다.**

### 개념·용어
- 1쪽: 지역 / 지역성 / 동질지역 / 기능지역 / 점이지역, 전통적 지역 구분(관북·관서·해서·관동·경기·호서·호남·영남)
- 3쪽: 종주도시, 교외화 현상
- 5쪽: 소비자 서비스업 ↔ 생산자 서비스업 (정의·입지·종류)
- 각 단원 각주(주석) — 시험 범위 아님, 애초에 제외

### 서술형 정리
- 2쪽: 수도권/영남권/호남권/충청권/제주권 인구
- 3쪽: 수도권의 범위와 지역 특색, 서울·인천·경기 서술, **수도권 1기·2기 신도시 목록**
- 4쪽: 수도권 공업 구조 변화(1960~2000년대)
- 5~6쪽: 충청 지방의 범위·특색, 산업 발달 요인, **주요 산업 단지 표**, 도시의 성장과 변화
- 9~10쪽: 강원 지방의 범위, 지형·기후·바람, 산업(농림수산업·광업·관광·공업)
- 12쪽: 호남 지방의 범위와 자연환경, 산업, **전남·전북 농업 통계표**
- 23~25쪽: 지구의 크기, 반구, 대륙의 경계

### 표
- 6쪽: **혁신도시 표**, **우리나라의 도청 소재지 표**
- 7쪽: **도별 인구 1위 도시 표**
- 14쪽: **도청 이전 사례 표**

> 표에 적힌 값들은 `docs/빈칸-정답-정리.md`에 전부 채워 두었습니다.
> 다만 **퀴즈 문제로는 나오지 않습니다.**

## 4. 아직 확인이 필요한 빈칸

학습지에 비어 있어 제가 추론해 채운 것 중 근거가 약한 것들입니다.

| 쪽 | 빈칸 | 채운 값 | 왜 애매한가 |
|---|---|---|---|
| 1쪽 | 관동 지방 = "경기도(= )의 동쪽" | 기전 | '='가 경기도의 다른 이름을 묻는 형태라 **기전(畿甸)**으로 봤습니다. 다만 관북·관서와 나란히 보면 "(철령)관의 동쪽"이 정석입니다 |
| 9쪽 | 영서 하천 지형 "( ) 하천과 ( )" | 감입곡류 하천 / 하안단구 | 각주 번호와 빈칸 순서가 어긋나 있습니다. 두 지형 모두 답인 건 확실하나 순서는 확인 필요 |
| 12쪽 | "( ) 지방은 강설량이 많은 편임" | 호남 서해안 | 인쇄 문장만으로는 범위가 불명확합니다 |
| 5쪽 | 충청 특색 ① "( )의 요지" | 교통 | 필기로 채워져 있으나 흐릿합니다 |

**아직 채우지 못한 것**: 12쪽 전남·전북 농업 통계표. 빈칸이 많고 인쇄된 순위만으로는
전남·전북 어느 행인지 확정할 수 없어 비워 두었습니다. 확실한 것은
"전남은 1차 산업 종사자 비중 전국 1위"뿐입니다.
