# 학습지 빈칸 정답 정리 (2026 지역 이해)

스캔본에서 **비어 있던 빈칸을 추론해 채운 것**을 학습지 쪽 순서대로 정리했습니다.
이미 손글씨로 채워져 있던 칸은 그대로 옮겼고, 새로 채운 칸은 그대로 두었습니다.

- ⚠️ 표시 = 근거가 약하거나 표현이 갈릴 수 있어 **수업/선생님 답과 대조가 필요한 항목**
- **학습지 하단 각주(주석)는 원칙적으로 시험 범위가 아닙니다.** 이해를 돕기 위해 선생님이
  넣어주신 것이라 기본 출제에서 뺐습니다. 다만 과년도 기출 12번 ㄷ(낙동강 발원지 너덜샘 = 각주 33),
  02번 ④(하안단구 정의 = 각주 26)처럼 **실제로 출제된 적이 있어** 지우지는 않고
  `notes` 필드에 따로 보관합니다. 홈 화면의 **'각주 내용 포함'**(14개)을 켜면 함께 출제됩니다.
  기본값은 꺼짐입니다. → [기출 분석](기출-분석.md)
  본문 빈칸의 답을 각주가 가리키는 경우(예: ⑯ 앤틸리스 제도)는 답 자체가 본문이라 그대로 둡니다.
- 스캔본에 포함된 범위: 학습지 **1~14쪽(001~005단원)**, **23~31쪽(009~0011단원)**
- 이 문서에 정리한 **본문 내용은 모두 앱에 들어가 있습니다.** 단원마다 '개관' 갈래로 묶었고
  (002 수도권 개관, 003 충청 개관, 004 강원 개관, 005 호남 개관, 009 지구와 대륙),
  단원 끝의 지역 정리표는 '시·군' 갈래입니다.
- **빠진 범위: 15~22쪽(영남권·제주 등 006~008단원)** → 받으면 같은 방식으로 추가하겠습니다.

## 23~25쪽 · 009 오대양 육대주

지구 나이 **46억년** · 반지름 약 **6,400km** · 적도 반지름 **>** 극 반지름 · 둘레 **4만km** ·
위도 1° ≈ **110km** · 자전축 기울기 **23.5°**(계절의 변화 원인) · 1해리 **1.852km** · 1시간에 1해리 = **1노트**
지구 중심에서 가장 먼 지점 = **침보라소 산(6,268m, 에콰도르)** *(모두 기재됨)*

**반구**: 북반구는 **적도** 중심 · 동반구는 **본초 자오선** 기준 ·
**육반구**(중심 **영국 해협**, 육지:해양 = 47:53) · **수반구**(중심 **뉴질랜드 남동**, 1:9) *(기재됨)*
