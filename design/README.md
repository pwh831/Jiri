# 디자인 캔버스 원본

앱 화면 디자인의 원본 파일입니다. 각 `.dc.html`이 캔버스의 아트보드 하나입니다.

| 파일 | 화면 |
|---|---|
| `Main.dc.html` | 홈 · 세션 설정 |
| `Typing.dc.html` | 서답형 출제 |
| `Feedback.dc.html` | 서답형 정답 |
| `Choice.dc.html` | 5지선다 채점 |
| `Result.dc.html` | 세션 결과 |
| `System.dc.html` | 디자인 시스템(색·활자·부품) |
| `AltNight.dc.html` `AltCard.dc.html` | 채택하지 않은 방향 스케치 |
| `canvas.json` | 아트보드 배치·페이지·메모 |

`_head.txt` / `_foot.txt`는 모든 아트보드가 공유하는 머리말·꼬리말(토큰과 폰트 정의)입니다.
캔버스를 다시 만들 때는 `/design`으로 이 파일들을 다시 씨앗으로 넣습니다.

## 디자인 방향 — 지리부도(Atlas)

학습지 지도가 흑백 스캔본이라 화면도 종이색·잉크색으로 맞췄습니다.
색은 지도 범례처럼 세 가지만 씁니다.

| 토큰 | 값 | 쓰임 |
|---|---|---|
| 종이 | `#F5F1E8` | 바탕 |
| 잉크 | `#1F1B16` | 본문·선택된 항목 |
| 물빛 | `#33596B` | 주요 동작·선택 |
| 숲빛 | `#4A6E44` | 정답·숙달 |
| 주기 | `#B0512C` | 지도 번호·오답 |

활자는 문제문·정답·점수에 고운바탕(serif), 본문과 조작에 IBM Plex Sans KR,
번호·눈금에 IBM Plex Mono를 씁니다. 웹폰트를 못 받는 환경에서는
바탕/애플명조와 시스템 고딕으로 대체됩니다.
