# 2026 지역이해 암기 퀴즈

수업 학습지(2026 지역 이해)를 지도 기반 퀴즈로 바꾼 암기 프로그램.

## 실행

`index.html`을 브라우저로 열면 바로 실행됩니다. 설치·빌드 필요 없습니다.

로컬 서버로 열고 싶으면:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## 문제 유형

| 유형 | 형태 | 예 |
|---|---|---|
| 서답형 | 지도 → 지역명 타이핑 | "지도의 7번 지역의 이름은?" → `순창` |
| 5지선다 | 지역명 → 특징 고르기 | "담양군에 대한 설명으로 옳은 것은?" |

- 접미어(시·군·도·강·섬·반도 등)는 있어도 없어도 정답 (`순창` = `순창군`)
- 괄호·공백 무시, 오타 1글자까지 정답 인정(정확한 표기를 함께 표시)
- 5지선다 오답 보기는 **같은 범위의 다른 지역 특징**에서 우선 추출하고,
  정답 항목이 실제로 가진 특징과 겹치는 문구는 제외

## 기능

- 범위 선택: 17개 시·도 / 수도권 / 충청권 / 강원권 / 호남권 / 반도 / 섬 / 바다 / 호수 / 해협 / 오대양
- 오답 우선 출제, 오답 노트 다시 풀기, 연속 3회 정답 시 숙달 처리
- 학습 기록은 브라우저에 저장(localStorage)

## 구성

```
index.html                  앱 전체 (UI + 퀴즈 엔진)
data/items.js               문제 데이터 131항목
assets/maps/*.png           학습지에서 추출한 지도 8장
docs/PRD.md                 제품 요구사항 정의서
docs/빈칸-정답-정리.md       학습지 빈칸을 추론해 채운 내역과 근거
```

## 데이터 추가

`data/items.js`의 `ITEMS` 배열에 객체를 하나 넣으면 됩니다.

```js
{ id:"yn01", map:"yeongnam", num:1, scope:"korea", category:"yeongnam",
  name:"포항시", aliases:["포항"],
  features:["제철 공업 발달","경상북도 인구 1위 도시"] }
```

번호가 인쇄된 지도는 `num`만, 백지도는 `marker:{x,y}`(백분율)를 씁니다.
새 카테고리는 `index.html`의 `CATS`·`KIND`에 한 줄씩 추가합니다.
