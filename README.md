# 2026 지역이해 암기 퀴즈

수업 학습지(2026 지역 이해)를 지도 기반 퀴즈로 바꾼 암기 프로그램.

## 실행

### 링크로 열기 (태블릿·휴대폰 권장)

https://claude.ai/code/artifact/d48ddac4-e922-44a7-a34f-f9dbf4927a3a

아이패드·안드로이드 태블릿은 내려받은 HTML 파일을 브라우저로 여는 길이 막혀 있어
파일 방식이 통하지 않습니다. 링크로 접속하세요.
데이터를 고친 뒤에는 `python3 build.py` 로 만든 `jiri-quiz-web.html` 을 같은 주소에 다시 발행합니다.

### 파일 하나로 (PC)

**`지역이해-암기퀴즈.html`** 이 파일 하나만 받아서 더블클릭하면 됩니다.
지도까지 안에 다 들어 있어서 폴더 구조도, 인터넷도 필요 없습니다.
PC에서는 이 파일 하나만 있으면 인터넷 없이도 돌아갑니다.

### 저장소를 통째로 받았다면

`index.html`을 여세요. 단, `data/`와 `assets/` 폴더가 **같은 자리에 함께 있어야** 합니다.
index.html만 따로 빼내면 지도와 문제 데이터를 못 찾아 빈 화면이 뜹니다.

### 고친 뒤 다시 합치기

```bash
python3 build.py     # → 지역이해-암기퀴즈.html 갱신
```

## 문제 유형

| 유형 | 형태 | 예 |
|---|---|---|
| **기출형** | 아래 여섯 유형을 섞어 냅니다 | 실제 시험에 나오는 형식만 |
| 지도 → 지명 | 지도 보고 이름 타이핑 | "지도의 7번 지역의 이름은?" → `단양` |
| 특징 → 지명 | 설명 보고 지역 5지선다 | "화강암의 심층 풍화로 형성된 침식분지" → 춘천시 |
| 보기 조합 | ㄱㄴㄷㄹ 중 옳은 것만 고르기 | "충청 지방의 인구 변화로 옳은 것만을 고른 것은?" → ⑤ ㄷㄹ |
| 오류 찾기 | 네 줄짜리 표에서 틀린 줄 | "다음 표에서 설명이 옳지 않은 것은?" → ② |
| 공통점 | 여러 지역을 묶는 속성 | 강화도·인제군·태안군 → 람사르 등록 습지 |
| O·X 판별 | 붙여 준 서술이 그 지역 것인지 | "양구군 — 화강암의 심층 풍화로 형성된 침식분지" → X (춘천시) |
| 지명 → 특징 | 특징 5지선다 | "담양군에 대한 설명으로 옳은 것은?" |
| 특징 떠올리기 | 보지 않고 떠올린 뒤 확인 | "태안군의 특징을 떠올려 보세요" → 6가지 확인 |

**기출형**은 과년도 기출이 실제로 쓰는 형식만 섞습니다. '특징 떠올리기'는 기출에
없는 방향이라 여기서 빠집니다 — 시험은 특징을 나열하라고 묻지 않고,
특징을 주고 지역을 묻거나 짝이 맞는지를 묻습니다.

### 속성 묶음

`data/items.js` 의 `GROUPS` — 같은 속성을 가진 지역을 세로로 묶은 표 20개
(화력발전소 3곳, 람사르 습지 3곳, 신기 습곡 산지 5곳 …).
'공통점' 문제의 재료이자, 요약 PDF 마지막 쪽의 '속성으로 묶어 보기' 부록입니다.
각 묶음에는 **왜 거기에 몰렸는지**(`why`)를 적어 두었습니다. 이유를 알면 목록이 짧아집니다.
'특징 → 지명'의 단서는 **그 지역에만 있는 특징**을 우선 고르고, 같은 특징을 가진
지역은 보기에서 빼서 답이 둘이 되지 않게 합니다.

- 접미어(시·군·도·강·섬·반도 등)는 있어도 없어도 정답 (`순창` = `순창군`)
- 괄호·공백 무시, 오타 1글자까지 정답 인정(정확한 표기를 함께 표시)
- 5지선다 오답 보기는 **같은 범위의 다른 지역 특징**에서 우선 추출하고,
  정답 항목이 실제로 가진 특징과 겹치는 문구는 제외

'O·X 판별'은 기출의 주력 형식(자료 속 오류 찾기 · 진술 O·X 채점)을 연습하려고 넣었습니다.
절반은 그 지역의 실제 학습지 문장을, 절반은 **같은 범위 다른 지역의 문장**을 붙이고,
틀렸을 때 그 문장의 진짜 주인이 어디인지 알려 줍니다. → [기출 분석](docs/기출-분석.md)

### 각주 내용 포함

학습지 각주는 원칙적으로 시험 범위가 아니지만, 기출 12번 ㄷ(낙동강 발원지 너덜샘 = 각주 33)처럼
출제된 사례가 있습니다. 그래서 각주 서술은 지우지 않고 `notes` 필드에 따로 두고,
홈 화면의 **'각주 내용 포함'**(14개)을 켤 때만 출제합니다. 기본값은 꺼짐입니다.

- 대단원 단위 또는 세부 갈래 단위로 범위 선택
- 오답 우선 출제, 오답 노트 다시 풀기, 연속 3회 정답 시 숙달 처리
- 학습 기록은 브라우저에 저장(localStorage)

## 시험 범위에서 뺀 것

학습지 하단 **각주(주석)는 시험 범위가 아니라** 이해를 돕는 설명이므로 기본 출제에서 뺐습니다.
다만 기출에 나온 적이 있어 `notes` 필드에 보관하고 홈의 '각주 내용 포함'으로 켤 수 있습니다.

## 지도

`assets/maps/` 의 지도 10장은 **학습지 원본 PDF(디지털본)에서 그대로 뽑은 것**입니다.
스캔본에서 뽑던 시절의 뭉개짐과 손글씨 비침이 없습니다.

```bash
python3 tools/extract_maps.py <학습지 원본 PDF>
```

지도 번호(①②③…)가 이미지가 아니라 PDF 텍스트로 얹혀 있는 쪽이 있어,
이미지를 꺼내지 않고 그 영역을 통째로 렌더링합니다. 잘라낼 영역은 스크립트 안에 적어 두었습니다.

17개 시·도 지도는 번호가 없어 `marker:{x,y}` 퍼센트 좌표로 위치를 찍습니다.
지도 그림이 바뀌면 이 좌표가 어긋나므로, 옛 지도와 새 지도를 겹쳐 보고 옮겨 주는 도구를 씁니다.

```bash
python3 tools/fit_markers.py <옛 지도> <새 지도> --write
```

## 요약 PDF (굿노트용)

`docs/지역이해-요약.pdf` — **시험 범위만** 추린 13쪽짜리 요약본.

```bash
python3 tools/make_summary.py
```

- 단원 → 갈래 → 항목 순으로, 지도가 있는 갈래는 지도를 먼저 싣고 번호별 목록을 붙입니다
- 마지막 쪽은 **속성으로 묶어 보기** 부록 (같은 속성을 가진 지역을 세로로 모은 20묶음)
- 범위 밖 단원(005 호남)과 각주는 들어가지 않습니다
- 글자가 벡터로 남아 굿노트에서 확대해도 깨지지 않고 검색도 됩니다
- HTML을 만들어 크로미움 헤드리스로 인쇄합니다. 나눔고딕은 길이가 0인 VTT 표가 있어
  크로미움이 통째로 거부하므로, 쓰는 글자만 남긴 부분집합을 만들어 심습니다

## 정답 지도 PDF (굿노트용)

`docs/지역이해-정답지도.pdf` — 학습지 항목을 지도 위에 이름과 특징까지 적어 놓은 정답본.

> 아직 **012 세계의 산맥과 하천(산맥 9 · 하천 14)** 은 이 PDF에 없습니다.
> `tools/places.py` 에 좌표를 넣어야 들어갑니다.

- A4 세로 9쪽 (세계 4쪽 + 한국 5쪽) — 위쪽에 지도, 아래쪽에 지역별 특징
- 완전 벡터라 굿노트에서 아무리 확대해도 깨지지 않고, 글자 검색도 됩니다
- 지명은 4색(파랑·주황·초록·자홍)으로 구분합니다. 가까이 붙은 지명끼리는
  반드시 다른 색이 되도록 배정해, 어느 이름이 어느 점인지 바로 보입니다.
  하단 목록의 이름 앞 점도 지도와 같은 색입니다
- 지도는 공개 자료로 새로 그렸습니다 (학습지 스캔본이 아님)
  - 세계: Natural Earth 국경 + GSHHG 해안선
  - 국내: 통계청 SGIS 기반 행정 경계 (시·도 굵은 선 / 시·군·구 가는 선)

고치거나 다시 만들 때:

```bash
pip install matplotlib "geopandas<1.0" koreanize-matplotlib basemap basemap-data-hires shapely
ln -sfn <site-packages>/mpl_toolkits/basemap_data <site-packages>/mpl_toolkits/basemap/data
python3 tools/fetch_boundaries.py    # 국내 행정 경계 (한 번만)
python3 tools/make_answer_maps.py
```

좌표는 `tools/places.py`, 특징은 `data/items.js`에서 가져옵니다.

## 데이터 추가

`data/items.js`의 `ITEMS` 배열에 객체를 하나 넣으면 됩니다.

```js
{ id:"yn01", map:"yeongnam", num:1, scope:"korea", category:"yeongnam",
  name:"포항시", aliases:["포항"],
  features:["제철 공업 발달","경상북도 인구 1위 도시"] }
```

번호가 인쇄된 지도는 `num`만, 백지도는 `marker:{x,y}`(백분율)를 씁니다.
새 단원은 같은 파일의 `UNITS`에, 세부 갈래는 `CATS`에 한 줄씩 추가하고
`index.html`의 `KIND`에 서답형 문제문에 쓸 낱말을 넣습니다.
